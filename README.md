## 📖 项目简介

**Meta-Test-Hub** 是一个独立开发的纯前端人格测评平台，整合了 MBTI、四元素气质、大五人格、依恋风格、霍兰德职业兴趣、VARK 学习风格六大测评体系。

所有数据均保存在浏览器本地（LocalStorage），无需后端服务器，保障用户隐私。支持历史记录对比、双模式报告切换、主题字体自定义、JSON 数据备份等完整功能。

- 🔤 **三档字体调节** — 标准 / 大 / 更大，全 CSS 变量覆盖
- 📜 **历史对比** — 多次测评结果雷达图叠加对比
- 💾 **数据备份** — JSON 导出/导入，LocalStorage 损坏自动恢复

## 📝 设计思路

### 为什么是单文件？

选择单 HTML 文件架构是基于以下考虑：
1. **零部署成本** — GitHub Pages / 任何静态托管即开即用
2. **隐私友好** — 所有数据本地存储，无网络请求
3. **可移植性** — 单文件即可分享，接收方双击可用
4. **性能优势** — 无网络延迟，首次加载即可交互

### 自研 SVG 图表引擎

未引入 Chart.js 等图表库，而是从零实现了柱状图和雷达图：
- 柱状图支持逐项动画延迟（110ms 间隔）
- 雷达图支持可配置轴数、颜色、填充动画
- 所有 SVG 通过 `innerHTML` 构建，无需外部依赖

### MBTI 手绘插画系统

16 种人格类型采用统一的视觉语言：
- **统一 viewBox** — `200 × 260`，确保风格一致
- **分组配色** — NT 紫 / NF 绿 / SJ 蓝 / SP 黄
- **纯 SVG path** — 每个小人由椭圆、圆、路径组成
- **细节差异** — 每种类型有专属头饰/配件/表情
